# Android — Unrolled

Kotlin + Jetpack Compose app.

## Build & run

```bash
cd android
./gradlew :app:assembleDebug
```

Or open `android/` in Android Studio.

## Layout

- `app/src/main/java/dev/rahier/picswipe/` — Kotlin sources
- `app/src/main/res/` — resources (values, mipmap, drawable)
- `app/build.gradle.kts` — module build config
- `build.gradle.kts`, `settings.gradle.kts` — project build config
